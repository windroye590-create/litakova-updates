# Літакова Комісія 1.2.26 / 149

Виправлено втрату нових відповідей під час фонового відновлення тренування
та передачі іспиту на інший ПК. Передача одразу блокує редагування до
підтвердження. Журнал відновлення зберігає повну чернетку, а не одне поле;
старі журнали залишаються сумісними.

Таймер враховує затримку запитів і не повертається назад. Якщо через
невизначеність мережевого часу показник досяг нуля, застосунок уточнює стан
на сервері та не надсилає команду дострокового завершення.

Виправлено імпорт питань Word/Excel із двома або трьома варіантами відповіді,
позначення використаних спроб у навчальній панелі та конкурентний запис через
старий маршрут локального сховища.

Оновлений Code.gs відновлює перервані ревізії, безпечно повторює заміну тесту,
повторює невдале додавання курсанта до спільної таблиці та одразу оновлює
доступність тестів після зміни групи. Великі іспити використовують один
незмінний знімок питань; історичні дублікати результатів показують новішу роботу.

Серверні виправлення потребують розгортання цього Code.gs у тому самому
вебзастосунку Apps Script. Встановлення EXE саме по собі сервер не оновлює.
Не запускайте повторне початкове налаштування чинної бази.

Оновлено застарілі тестові сценарії та додано регресії для знайдених збоїв.
