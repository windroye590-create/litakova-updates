# Літакова Комісія для Windows 1.2.19 / 142

Повернуто збережений вхід: після закриття й повторного запуску програма відкриває останній акаунт на цьому ПК, зокрема без інтернету. Після оновлення з 1.2.18 увійдіть один раз.

Кнопка «Вийти» прибирає автоматичний вхід. Потім можна ввійти під іншим користувачем; наступного разу відкриється його акаунт. Пароль не зберігається. Ключ останнього акаунта захищений поточним профілем Windows; приватні дані й перевірені резервні копії залишаються зашифрованими.

Сервер залишається API 22. Оновлення використовує чинний підписаний канал.
