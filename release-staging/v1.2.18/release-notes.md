# Літакова Комісія для Windows 1.2.18 / 141

- Великі локальні чернетки зберігаються частинами. Повторна синхронізація не додає зайвих копій у профіль.
- Дані кожного акаунта зашифровані окремо. Після виходу приватні кеші блокуються; після перезапуску введіть пароль свого акаунта.
- Після першого входу на оновленому сервері локальну копію можна розблокувати без інтернету.
- Профіль і журнали відповідей мають три перевірені резервні копії. Пошкодження нової копії запускає відновлення; помилки доступу показуються користувачеві.
- Старі локальні дані переносяться після входу власника та перевірки нової копії. Решта акаунтів зберігається.

Сумісний сервер: API 22 / pc-1.2.18-private-storage-backups. Для першого перенесення старих локальних даних потрібен інтернет.
Оновлення підписано тим самим ключем RSA-3072, який перевіряє встановлений застосунок.
