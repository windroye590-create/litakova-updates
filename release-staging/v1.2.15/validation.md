# Перевірка 1.2.15 / 138, API 20

Виправлення двох дефектів, підтверджених стрес-тестом 2 листопада 2026 року:

* Відкладена публікація результатів і письмових оцінок у спільну таблицю тепер має довговічну позначку в основному рядку результату, обмежений обсяг повторів і явний стан у клієнті.
* Ручне оновлення таблиці звіряє стандартні поля всіх робіт з основною базою та зберігає додаткові колонки інструкторів.

Нові перевірки `public-table-sync.mjs` і `public-table-sync-ui.mjs` охоплюють збої публікації, втрату підтвердження, повторні оцінки, фонове відновлення, зміну облікового запису, перезапуск клієнта, зайняте блокування, міграцію API 19, часткове ручне оновлення, очищення набору й видалення результату.

Історичний тест, який вимагав збереження вручну зміненого стандартного числа правильних відповідей, оновлено відповідно до запитаного виправлення. Він тепер перевіряє відновлення значень з основної бази. Додаткові користувацькі колонки перевіряються окремо.

Серверні та браузерні випробування виконано на ізольованих синтетичних даних. Вони не визначають реальну квоту Google Apps Script або кількість фізичних Windows-комп’ютерів. Активація робочого сервера та публікація автооновлення фіксуються окремо після успішного виконання.
