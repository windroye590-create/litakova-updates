# Літакова Комісія для Windows 1.2.22 / 145

- Біля «Перевірка робіт» показується кількість робіт, які очікують перевірки, включно з відновленими іспитами. Лічильник оновлюється після завантаження черги та оцінювання.
- У каталозі інструктора додано позначки «Відкритий / Закритий / Чернетка». Враховується вибрана група; для різного доступу груп показується уточнення.
- «Ще» перейменовано на «Налаштування» та перенесено вниз бічного меню.

Збережений вхід, правила доступу та сервер API 23 сумісні. Оновлення підписано тим самим ключем RSA-3072, який перевіряє встановлений застосунок.
