# Літакова 1.2.42 / 166 — остання спроба і рейтинг

Після виправлення слів у тесті публікація створює новий ID і архівує
попередню версію. Підсумки за окремими ID помилково рахували їх як різні
тести. Сервер тепер віддає canonicalTestId за збереженим зв’язком replaces
у квитанції публікації. Нові заміни від старих клієнтів також зберігають
цей зв’язок. Самостійно створені однойменні тести не об’єднуються.

Спільний модуль вибирає останню роботу за часом завершення та ID при рівному
часі. Його використовують кабінет курсанта, рейтинг і відомість Excel.
Нижчий бал останньої спроби замінює вищий попередній. Історію робіт не
видалено. Рейтинг зберігає групу, записану під час складання роботи.

Змінено відбиток ревізій workspace, щоб після серверного оновлення всі ПК
отримали нові метадані. Видалені ID прибираються зі списку кешованих робіт,
включно з об’єднаними нестабільними знімками.

У чинній Google Таблиці виявлено порожнє джерело зведеної таблиці та
посилання на порожню колонку P замість ПІБ. Збережено локальну резервну
копію, замінено лише обчислення рейтингу, додано групу та службовий ключ
тесту. Формули спочатку перевірено у вільному діапазоні, включно з перездачею
на нижчий бал; тимчасові клітинки очищено. Значення 40 вихідних робіт
не змінювались. Формули відтворюються через release-tools/ranking_sheet.py.

Приховану колонку ключів заповнює власник Apps Script за ID результату.
Ця міграція не відновлює стару резервну вкладку і не переносить ручні
колонки. Після втрати відповіді її можна продовжити без повторного додавання
колонки. Сумісність API 26 і адресу сервера збережено.

Перевірки: 8 нових сценаріїв клієнта / сервера / міграції / Excel; модель
результатів, міграція таблиці, публікація, повний npm test; браузерні сценарії
рейтингу та «Моїх результатів»; перевірки складання і вбудованих ресурсів.
Робочі акаунти для проходження тестів не використовувалися.
