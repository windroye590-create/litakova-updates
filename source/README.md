# Літакова Комісія для Windows 1.2.30 / 154

Розробник — Дзюбленко Денис Олександрович (Дімон).

Картка курсанта відкривається натисканням ПІБ у розділі «Курсанти».
Вона об’єднує історію робіт, матеріали та спільні примітки інструкторів.
Стабільний випуск доступний через автооновлення GitHub.
Повний перелік — у [примітках випуску](release-notes.md).

[Збирання Windows](docs/BUILD-UA.md) · [Карта файлів](docs/FILE-MAP-UA.md) ·
[Розгортання серверних виправлень](docs/RELIABILITY-UA.md)

`npm test` включає регресії для відтворених помилок. `npm run test:ui`
перевіряє інтерфейс, а `npm run test:packaged` — ресурси готового EXE.

Сервер Apps Script має окреме розгортання. Номер сумісного API залишається 26,
ідентифікатор серверного випуску визначає автоматизація перед розгортанням.
