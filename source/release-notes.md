# Літакова Комісія для Windows 1.2.28 / 152

У розділі «Результати» тепер три вкладки:

- **Усі результати** — таблиця, відкриття роботи, відомість PDF та CSV.
- **Очікують перевірки** — письмові роботи та збережені іспити для підтвердження.
- **Рейтинг** — результати всіх тестів обраної групи.

Група та тест зберігаються при перемиканні вкладок. Кожна вкладка запам'ятовує
свій пошук. Після перегляду або оцінювання робота повертає до попередньої
вкладки з її фільтрами й пошуковим запитом. Лічильник біля «Результатів»
показує кількість робіт, що очікують перевірки.

Окремий пункт «Перевірка робіт» прибрано з меню. Збережено чернетки оцінок,
коментарі, авторство та блокування роботи під час перевірки іншим інструктором.

Стабільний випуск поширюється через чинний канал автооновлення GitHub.
Він також встановлюється поверх попереднього перегляду 1.2.28 / 151.

Зміни інтерфейсу сумісні з чинним Apps Script API 26.
Автоматизація перевіряє сервер перед публікацією.
