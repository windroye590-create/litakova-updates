# Літакова Комісія для Windows 1.2.29 / 153

- На «Головній» прибрано блок фільтрів. Статистика завжди показує загальний огляд.
- У «Тестах» залишено вибір групи та пошук за назвою.
- У «Курсантах» залишено вибір групи та пошук за ПІБ або логіном.
- У «Результатах» та «Аналітиці» залишено групу й тест.
- У «Матеріалах» фільтри відкриваються кнопкою «Фільтри». У згорнутому стані
  видно кількість активних умов та вибрану групу й тест.

Фільтри розділів незалежні, а пошук у списках зберігається при переходах
і після перезапуску. Скидання фільтрів одного розділу не змінює решту.
Збережений раніше спільний вибір групи й тесту перенесено до «Результатів».

Стабільний випуск поширюється через чинне автооновлення GitHub.
Зміни сумісні з чинним Apps Script API 26.
