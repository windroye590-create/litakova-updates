# Синхронізація спільної таблиці

Версія ПК 1.2.15 / 138, сервер API 20.

Прийняття відповідей курсанта й публікація їхньої копії у спільній Google Таблиці мають окремий стан. Збій таблиці не скасовує вже прийняту роботу.

## Автоматичне відновлення

Ознака незавершеної публікації записується разом із відповідями в тому самому рядку основної бази. Вона залишається після втрати з’єднання, відповіді сервера чи перезапуску ПК. Для письмової роботи зберігається найновіша оцінка.

Після тимчасової помилки сервер витримує паузу 30 секунд. Наступні успішні запити користувачів виконують не більше двох відкладених публікацій за один запит. Клієнт із незавершеною синхронізацією перевіряє її стан кожні 10 секунд. Якщо ніхто не користується застосунком, робота продовжиться після наступного входу або запиту. Окремий часовий тригер Google не потрібен.

Попередження «Результати збережено в застосунку. Спільна Google Таблиця очікує синхронізації…» показує різницю між прийняттям роботи та оновленням таблиці. Воно зникає після підтвердження публікації. Курсант бачить стан власних робіт, інструктор бачить стан спільної таблиці.

Оновлення з API 19 одноразово позначає історичні результати для звірки з таблицею. Питання, відповіді та оцінки при цьому не змінюються. Під час підготовки нового набору автоматична публікація призупинена й не повертає видалені роботи.

## Кнопка «Оновити таблицю»

У розділі «Ще», у блоці «Таблиця результатів», команда звіряє стандартні поля всіх наявних результатів з основною базою за ID. Вона виправляє також звичайні тести без письмових питань, відновлює пропущені рядки та зберігає додаткові колонки праворуч від стандартних полів.

Для зміни письмової оцінки використовуйте перевірку роботи в застосунку. Стандартні значення копії в Google Таблиці відновлюються з основної бази, якщо їх змінено вручну.

## Встановлення серверного виправлення

Потрібно оновити Code.gs чинного проєкту до API 20 та створити нову версію його наявного розгортання. Адресу, таблицю і права доступу слід зберегти. Старі клієнти продовжують працювати із сервером API 20; нове попередження доступне у ПК 1.2.15.

Під час цієї зміни не потрібно запускати підготовку нового набору або видаляти курсантів.
