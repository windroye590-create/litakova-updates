# Серверні виправлення 1.2.26

Цей файл описує підготовлений код. Факт розгортання перевіряється окремо
за відповіддю чинної адреси вебзастосунку.

1. Збережіть приватну резервну копію поточного коду Apps Script.
2. У чинному проєкті замініть Code.gs файлом цього випуску.
3. Створіть нову версію й оновіть наявне розгортання зі збереженням його
   адреси, виконавця та правил доступу.
4. Перевірте GET чинної адреси: `version: 26`,
   `serverBuild: pc-1.2.26-audit-reliability`, `status: online`.

Повторне `setupCommission()` не потрібне. Не очищайте службові аркуші,
властивості, облікові записи або активні роботи.

Під час першого запиту сервер додає десяту службову колонку користувачів
для стійкого стану публікації. Наявні курсанти один раз потрапляють до черги
перевірки публічних рядків; повтори не створюють дублікати. Обсяг роботи за
один запит залишається обмеженим.

Новий формат спроби іспиту зберігає незмінний набір питань і порядок їх ID.
Попередні повні знімки читаються та перетворюються під час наступного запису.
Курсантам повертається сумісне повне представлення без ключів правильних
відповідей. Після появи компактних спроб не відкочуйте сервер до старого
Code.gs: попередній код не розуміє цей внутрішній формат. Для відкату потрібне
окреме перетворення активних знімків зі збереженням відповідей та строків.

Публікація автооновлення потребує оригінального RSA-3072 ключа. Приватний
ключ та файли паролів зберігаються поза кодом, публічним пакетом і GitHub.
