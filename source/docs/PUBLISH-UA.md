# Публікація підписаних оновлень Windows

Канал: https://github.com/windroye590-create/litakova-updates

Установлені програми читають постійну адресу
https://github.com/windroye590-create/litakova-updates/releases/latest/download/updates.txt
і завантажують Litakova-Komisiia-PC.exe з того самого випуску.

## Підготовка наступної версії

1. Узгодьте нові назву й код версії у package.json, web/core.js,
   native/update_protocol.h і серверних метаданих Code.gs. Код має збільшуватися.
2. Перевірте зміни, зберіть EXE через build_windows.py.
3. Сформуйте підписаний комплект через release-tools/publish_updates.py
   за інструкцією BUILD-UA.md. Оригінальний приватний ключ лишається поза кодом
   і репозиторієм. У GitHub зберігається тільки відкритий ключ перевірки.
4. Перевірте комплект командами:

   python3 tests/update_protocol.py /path/to/public-bundle
   python3 release-tools/github_release.py /path/to/public-bundle --verify-only

5. У робочій копії репозиторію каналу замініть чотири файли каталогу channel:
   Litakova-Komisiia-PC.exe, updates.txt, icon.png та index.html.
   Оновіть release-notes.md, збережіть зміни комітом і надішліть main у GitHub.

## Що публікується автоматично

Workflow .github/workflows/publish-signed-release.yml перевіряє підпис,
версію, розмір і SHA-256 EXE та запускає перевірки публікатора.
Потім створює чернетку випуску, завантажує всі чотири файли й повторно
завантажує кожен із GitHub для побайтової перевірки.

Лише після завершення перевірок випуск стає публічним та latest.
Перервана передача лишає попередній стабільний випуск чинним.
Повторний запуск продовжує незавершену чернетку, а повторна публікація
того самого комплекту не створює дубля. Старіший номер збірки не замінює новіший.
Опубліковані файли не перезаписуються: для зміненого EXE потрібна нова версія.

Для публікації використовується штатний короткочасний GITHUB_TOKEN workflow
з дозволом contents: write. Приватний ключ і його пароль у GitHub не передаються.

## Перевірка після публікації

Відкрийте сторінку останнього випуску та переконайтеся, що вона містить нову
версію і чотири файли. На ПК натисніть «Перевірити оновлення».
Застосунок завантажить комплект і перевірить оригінальний підпис та SHA-256.
Перед заміною EXE він збереже стан і перезапуститься. Активний іспит або
незавершене збереження відкладають встановлення.
