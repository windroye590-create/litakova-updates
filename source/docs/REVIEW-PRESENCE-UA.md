# Спільна перевірка робіт — ПК 1.2.13 / API 18

У списку «Перевірка робіт» видно, хто зараз перевіряє конкретну роботу.
Резервується результат одного тесту одного курсанта. Його інший тест може
одночасно перевіряти інший інструктор.

- «Вільна для перевірки» — натисніть «Почати перевірку».
- «Перевіряє: ПІБ» — відповіді можна переглядати; бали й коментарі змінює
  поточний перевіряльник.
- «Ви перевіряєте цю роботу» — інші інструктори бачать ваше ім’я.
- «Перевірка призупинена» — зв’язок або право редагування не підтверджено.
  Чернетка залишається на ПК. Після відновлення зв’язку можна почати перевірку
  знову; застарілі коментарі зберігаються для порівняння.

Після виходу зі сторінки або збереження перевірки резервування звільняється.
Якщо ПК закрився без повідомлення серверу, воно спливає через 120 секунд
після останнього підтвердження. Статуси перевіряються кожні 25 секунд у
відповідному розділі. Бали й коментарі потрапляють до результату після
«Зберегти перевірку»; можна зберігати частково.

Сервер підтверджує право збереження, термін і ревізію оцінок. Навіть старий ПК
не може перезаписати роботу з активною спільною перевіркою. Повтор запиту після
втрати відповіді не створює повторної оцінки. Після нового резервування старий
запит звільнення чи підтвердження не впливає на нову перевірку.

Оновлення статусів читає невеликий набір властивостей, без сканування історії
результатів. Повний список запитується при зміні результатів. Підтвердження
присутності не змінює ревізій оцінок і не додає записів до журналу перевірок.

Для активації потрібні ПК 1.2.13 і сервер API 18. Чинний Code.gs потрібно
оновити у тому самому проєкті Apps Script, а в керуванні розгортанням обрати
нову версію для наявного вебзастосунку. Адреса /exec, доступи й база лишаються
поточними. Нових дозволів Google або окремих платних сервісів не потрібно.
На старому сервері застосунок прямо повідомляє про відсутність спільного
статусу; попередня перевірка ревізій зберігається.
