# Де що змінювати

| Файл або папка | Призначення |
| --- | --- |
| web/app.js | Екрани, редактор та ручна перевірка |
| web/results.js | Компактна таблиця результатів, рейтинг групи за всіма тестами та CSV рейтингу |
| web/style.css | Світла й темна теми та розміщення елементів |
| web/account-sync.js | Чернетки акаунта, ревізії, повтори та конфлікти між ПК |
| web/core.js | Версія, URL серверного API й правила тестування |
| web/office-import.js | Імпорт тестів із Word та Excel |
| web/materials.js | PDF-матеріали й офлайн-доступ |
| web/statement.js | Відомість групи у PDF |
| web/vendor | Необхідні сторонні бібліотеки, шрифти та ліцензії |
| native/main.c | Запуск програми, адреса нативного запиту й обмін із сервером |
| native/update_protocol.h | Версія та адреса каналу оновлень |
| native/updater.h | Завантаження й установлення підписаного EXE |
| Code.gs | Сервер Google Apps Script API 26 |
| build_windows.py | Збирання Windows EXE |
| release-tools | Підготовка підписаних випусків і ярликів |
| tests | Поточні перевірки та тестові дані |

Багато файлів у web/vendor/pdfjs потрібні для різних PDF, шрифтів і мов.
Вони належать одній бібліотеці перегляду, а не окремим випускам застосунку.
Тестові дані використовуються тільки перевірками.
Адреса сервера узгоджується у CLOUD_URL в web/core.js та у шляху
WinHttpOpenRequest у native/main.c. Після зміни потрібне нове збирання.

web/exam-session.js — серверна спроба іспиту, передача між ПК, початковий строк завершення.
tests/exam-resume.mjs — 22 сценарії продовження іспиту на різних ПК.

Code.gs: deleteTest_ прибирає тест зі списку, зберігаючи визначення
для результатів і письмових робіт. tests/test-deletion.mjs — 17 перевірок
цього видалення, прав, оновлення каталогу, повторів і розпочатого іспиту.

Code.gs: loginAttempt_ захищає вхід; routeExamRecovery_ зберігає старі роботи та приймає підтвердження інструктора. tests/auth-recovery.mjs перевіряє ці сценарії на чинному серверному файлі.
