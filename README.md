# Літакова Комісія — оновлення Windows

[Завантажити програму](https://github.com/windroye590-create/litakova-updates/releases/latest/download/Litakova-Komisiia-PC.exe)
 · [Останній випуск](https://github.com/windroye590-create/litakova-updates/releases/latest)

У застосунку відкрийте «Ще» / «Профіль» → «Перевірити оновлення».
Програма завантажить новий випуск, збереже стан і перезапуститься.
Під час активного тесту встановлення відкладається.

Публічний випуск доступний за посиланням «Останній випуск» вище.
Вихідний код для наступних випусків — у [source/](source/).

## Автоматичний випуск

Один процес збирає та перевіряє Windows EXE, підписує каталог, за потреби
оновлює чинний Apps Script і публікує автооновлення після перевірки сервера.
[Одноразове підключення й запуск випуску](docs/AUTOMATION-UA.md).

Ручна заміна channel не публікує випуск. Підготовлені кандидати й архіви
коду можуть з'являтися в Git до публікації; програма завантажує лише
перевірений публічний Releases/latest. Приватні файли до Git не додаються.
