# Літакова Комісія — оновлення Windows

[Завантажити програму](https://github.com/windroye590-create/litakova-updates/releases/latest/download/Litakova-Komisiia-PC.exe)
 · [Останній випуск](https://github.com/windroye590-create/litakova-updates/releases/latest)

У застосунку відкрийте «Ще» / «Профіль» → «Перевірити оновлення».
Програма завантажить новий випуск, збереже стан і перезапуститься.
Під час активного тесту встановлення відкладається.

Поточний випуск — **1.2.27 / 150**. Виправлено колонки «Час» та «Дії» у результатах: час не переноситься вертикально, кнопки видалення розташовано окремо. [Перелік змін](release-notes.md). Сервер 1.2.26 сумісний; повторне розгортання Apps Script для цього випуску не потрібне.

## Публікація наступного випуску

Замініть чотири підписані файли в channel і оновіть release-notes.md.
Після коміту в main GitHub Actions перевіряє оригінальний підпис і контрольні
суми, завантажує та перевіряє всі файли в чернетці випуску й лише тоді
перемикає канал на нову версію.

Повторний запуск продовжує незавершену передачу. Опубліковані файли
не перезаписуються; старіший номер збірки не замінює новіший.
Приватний ключ підпису та його пароль до репозиторію не додаються.
