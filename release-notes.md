# Літакова Комісія — Windows 1.2.16 / 139

Виправлено зависання на «Відкриваємо кабінет…» після встановлення 1.2.15. До EXE включено відсутній модуль синхронізації. Пакування тепер автоматично охоплює весь публічний каталог інтерфейсу.

Якщо інтерфейс не може запуститися, заставка показує кнопки повторного запуску й завантаження актуальної програми. Збережені результати, обліковий запис і чернетки не очищаються.

Для завислої 1.2.15: закрийте вікно, завершіть процес Litakova-Komisiia-PC.exe у Диспетчері завдань і замініть старий EXE завантаженим 1.2.16. Папку даних у LOCALAPPDATA не видаляйте. Якщо процес не завершувати вручну, він може утримувати попередній інтерфейс до чотирьох хвилин.

Сервер API 20 та попередні виправлення синхронізації залишаються чинними.
