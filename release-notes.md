# Літакова Комісія 1.2.28 / 152

«Результати» та «Перевірку робіт» об'єднано в одному розділі з трьома вкладками:

- **Усі результати** — таблиця, перегляд роботи, відомість PDF та CSV.
- **Очікують перевірки** — письмові роботи та збережені іспити для підтвердження.
- **Рейтинг** — результати всіх тестів обраної групи.

Під час перемикання вкладок зберігаються група та тест, а кожна вкладка
запам'ятовує свій пошук. Після перегляду або оцінювання робота повертає
до попередньої вкладки з її фільтрами й пошуком. Лічильник біля
«Результатів» показує кількість робіт, що очікують перевірки.

Збережено чернетки оцінок, коментарі, авторство, блокування роботи під час
перевірки іншим інструктором та виправлене відображення часу в таблиці.

Це стабільний випуск 1.2.28 / 152 без позначки «Перегляд».
Автооновлення працює зі стабільного 1.2.27 та попереднього перегляду 1.2.28 / 151.
Використовується чинний Apps Script API 26 та спільна база комісії.
