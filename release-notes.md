# Літакова Комісія 1.2.46 / 170

Прискорено пошук і перемикання рейтингу: повторні дії використовують розрахований кеш, який автоматично скидається після зміни результатів, тестів або курсантів.

Список робіт на перевірку й відновлені іспити завантажуються одним запитом. Незмінний список перевіряється за ревізією без повторного читання всієї історії. Для першого читання великої історії сервер вибирає лише діапазон незавершених робіт. Ручне оновлення перечитує дані повністю.

Пакети одночасних збережень профілю об’єднуються в один запис. Відповіді підтверджуються лише після успішного запису; зміни, внесені під час запису, зберігаються наступним пакетом.
