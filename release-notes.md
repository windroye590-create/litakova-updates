# Літакова Комісія — Windows 1.2.17 / 140

Виправлено три дефекти збереження й відновлення відповідей:

- Помилка читання файла Windows більше не відкриває порожній профіль і не дозволяє перезаписати непрочитані дані.
- При помилці журналу відповідей програма показує повторний запуск; старіші відповіді не записуються поверх останнього збереження.
- Розпочате тренування переноситься між ПК разом із дозволом на здачу. API 21 перевіряє цей дозвіл і дозволяє продовжити вже розпочату роботу після закриття тесту інструктором.

Права доступу, одна прийнята спроба та захист одночасного оцінювання збережені.
Облікові записи, чернетки та результати не очищаються. Сервер API 21 потрібен
для захищеного відновлення тренування. Старі копії, перенесені без дозволу,
можуть потребувати повторної синхронізації з початкового ПК.

Встановлення: скористайтеся автооновленням або закрийте програму й замініть
попередній EXE новим. Папку даних LOCALAPPDATA\LitakovaKomisiiaPC не видаляйте.
