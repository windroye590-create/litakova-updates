# Літакова Комісія 1.2.30 / 154

Додано **картку курсанта**. У розділі «Курсанти» натисніть ПІБ.

- **Тести й результати:** повна історія робіт за ID курсанта, включно з попередніми
  групами, оцінки, письмові роботи на перевірці та тести без завершеного результату.
- **Матеріали:** доступні та раніше переглянуті чинні матеріали, остання сторінка
  й прогрес поточної версії PDF. Перегляд сторінок не прирівнюється до засвоєння.
- **Примітки:** спільні записи інструкторів з автором і датою; курсанти їх не бачать.

Роботу можна відкрити й оцінити з картки. Після перегляду або збереження оцінок
програма повертає до того самого курсанта. Повернення до списку зберігає його
фільтри, пошук і сторінку. Збережена картка доступна під час збою зв’язку
з відповідною позначкою; чернетка примітки зберігається на цьому ПК.

Повторне надсилання примітки після втраченої відповіді не створює дубліката.
Повне видалення курсанта та підготовка нового набору очищають пов’язані примітки.

Стабільний випуск **1.2.30 / 154** включає сумісне доповнення Apps Script API 26.
Автоматизація оновлює чинне розгортання перед публікацією EXE.
