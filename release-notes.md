# Літакова Комісія 1.2.31 / 155

Об’єднано верхні кнопки «Синхронізувати» та «Оновити» в одну — **«Оновити дані»**.

Кнопка спочатку зберігає локальні зміни, надсилає результати й прогрес матеріалів,
оновлює дані відкритого розділу та синхронізує чернетки акаунта. Картка курсанта,
матеріали, черга перевірки, банк питань та аналітика оновлюються через той самий процес.

Повторні натискання приєднуються до поточного циклу. Зайву повторну синхронізацію
акаунта всередині ручного оновлення прибрано. Фонові операції чекають завершення
цього циклу; збереження активного іспиту й утримання перевірки продовжують працювати.

Помилки запису, невідправлені результати й конфлікти чернеток відображаються
окремо та зберігають свої дії відновлення. Перемикання акаунта припиняє решту
операцій попереднього користувача.

Стабільний випуск **1.2.31 / 155**, сумісний із чинним Apps Script API 26.
