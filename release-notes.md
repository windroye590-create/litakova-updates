# Літакова Комісія для Windows 1.2.20 / 143

- Виправлено пошкодження великих тестів під час очищення набору; цілі переміщені частини попередніх тестів знову читаються з перевіркою контрольної суми.
- Тимчасовий збій Google більше не підмінює спільну таблицю результатів новою.
- Усунуто гонку входу під час зміни пароля та часткове застосування пароля за помилки відкликання сеансів.
- Узгоджено ліміти для синхронізації великих чернеток; коди запрошень приховано з інструкторського журналу.
- Повтор після втраченої відповіді на створення нового тесту повертає вже створений тест, а нові локальні правки зберігаються.
- Збережений вхід останнього акаунта на ПК залишається; «Вийти» прибирає його.

Сумісний сервер API 23 уже активовано на тій самій адресі. Перевірено повний набір моделей, усі браузерні сценарії, 27 одночасних ізольованих клієнтів та 16 сценаріїв реального Windows-хоста.
Оновлення підписано тим самим ключем RSA-3072, який перевіряє встановлений застосунок.
