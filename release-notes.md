# Літакова Комісія для Windows 1.2.25 / 148

- «Курсанти → Видалити повністю» очищає акаунт, проходження, відповіді, чернетки перевірки й пов’язані рядки у спільній Google Таблиці.
- «Результати → Таблиця результатів» дає змогу видалити окрему роботу. Використану спробу цього тесту зараховано.
- Старі рядки очищаються після однозначної прив’язки до курсанта. Перерване видалення можна повторити.

Для цих дій потрібен сервер Google Apps Script API 26. Оновлення для Windows підписано чинним ключем RSA-3072.
