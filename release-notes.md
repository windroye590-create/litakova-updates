# Літакова Комісія 1.2.36 / 160

Літакова Комісія — видалення акаунтів зі старими результатами без ID.

- Перед видаленням курсанта застосунок показує старі рядки, належність яких сервер не може визначити однозначно. Для кожного рядка потрібно вибрати: видалити разом із цим акаунтом або залишити для іншої людини.
- Вибір діє лише для цього курсанта, інструктора й незміненого рядка. Зміна даних або завершення строку підтвердження потребує нового перегляду.
- Рядки з ID іншого курсанта та записи, обрані для збереження, залишаються в таблиці. Суперечливі ID продовжують блокувати видалення.
- Після видалення останнього курсанта можна видалити порожню групу, якщо вона не призначена тестам.

Потрібен чинний сервер API 26 із цим виправленням; процес випуску оновлює його перед публікацією EXE. Додано серверні та браузерні регресії для старих рядків, тезок, зміни даних після перегляду й видалення групи.
