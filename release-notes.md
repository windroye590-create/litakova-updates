# Літакова Комісія для Windows 1.2.21 / 144

- Кнопку «Синхронізувати» перенесено у верхню панель поруч із вибором теми та «Оновити».
- Звичайний широкий блок синхронізації прибрано. Під час роботи кнопка показує «Синхронізуємо…», а її підказка — стан акаунта.
- Попередження про помилки збереження, конфлікти між ПК та відновлення копій залишаються видимими з потрібними діями.

Логіка синхронізації, збережений вхід і сервер API 23 залишаються сумісними. Оновлення підписано чинним ключем RSA-3072.
