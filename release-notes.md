Літакова Комісія для Windows 10/11 x64. Версія 1.2.10, збірка 133.

Зміни:

- Компактна таблиця результатів: ПІБ, правильні відповіді, помилки, результат і час.
- Натискання ПІБ або назви тесту відкриває роботу та перевірку відповідей.
- Окремий рейтинг групи за всіма тестами: кожен тест у власній колонці, підсумок — сума правильних відповідей.
- Пошук, фільтри групи й тесту, експорт CSV для Excel та PDF-відомість одного тесту.
- Непройдені тести відрізняються від нульового результату. Дублі й непідтверджені роботи не збільшують рейтинг.
- Збережено захист входу, підтвердження старих збережених робіт інструктором, письмові відповіді та синхронізацію між ПК.

Оновлення: «Ще» / «Профіль» → «Перевірити оновлення». Застосунок завантажує підписаний EXE, зберігає стан і перезапускається. Під час активного тесту або незбереженої роботи встановлення відкладається.

Робочий сервер перевірено: API 16 / pc-1.2.9-auth-recovery. Для чинної комісії Code.gs повторно замінювати не потрібно.
