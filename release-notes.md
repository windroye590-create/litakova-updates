# Літакова Комісія для Windows 1.2.23 / 146, API 24

- Повторні проходження тестів вимкнено. Інструктор також не може видати персональну повторну спробу.
- Раніше створені персональні повтори приховано й заблоковано на сервері. Старі результати та перевірка відповідей збережені.
- Прибрано створення та імпорт чернеток персональних повторів і застарілу підказку про дозвіл повтору інструктором.
- Продовження незавершеної звичайної роботи, початковий таймер і повторне надсилання того самого результату збережено.

Сервер API 24 активовано в чинному розгортанні. Chromium, Windows і повні регресійні перевірки пройдено. Оновлення підписано чинним ключем RSA-3072.
