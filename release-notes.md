Літакова Комісія для Windows 10/11 x64. Версія 1.2.14, збірка 137.

- Постійний каталог тестів між наборами. Нові тести з ПК 1.2.14 публікуються закритими.
- «Керувати доступом»: відкриття й закриття для окремої групи або всіх призначених груп. Назви закритих тестів видно курсантам.
- Початок перевіряється сервером; завантажена копія не обходить закриття. Розпочаті тренування можна завершити офлайн й надіслати після підключення. Розпочаті іспити зберігають свій таймер.
- «Курсанти» → «Підготувати новий набір»: перегляд кількостей усіх груп, необов’язковий CSV для Excel та окреме підтвердження.
- Очищення прибирає курсантів, проходження й відповіді, закриває тести та зберігає інструкторів, групи, матеріали, банк питань і чернетки тестів.
- Перервану підготовку можна продовжити з іншого ПК. Повторення запиту не видаляє вже зареєстрований наступний набір.

Оновлення саме по собі не очищає робочу базу. Для нових дій потрібні ПК 1.2.14 та сервер API 19. Оновлений приватний Code.gs надається власнику окремо; чинні адресу /exec, базу та права доступу потрібно зберегти. Інструкція: server/TEST-ACCESS-INTAKE-UA.md.
