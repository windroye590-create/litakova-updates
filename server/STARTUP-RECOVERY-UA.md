# Відновлення запуску після 1.2.15

Причина зависання: модуль `public-table-sync.js` імпортувався застосунком, але був відсутній у списку додаткових ресурсів Windows EXE. Браузер не міг виконати граф модулів і залишав початкову заставку. Серверна база до цього етапу ще не завантажувалась.

У 1.2.16 / 139 пакування автоматично включає весь публічний каталог `web`. Перевірка читає ресурси й таблицю маршрутів безпосередньо з PE, порівнює їхні байти з джерелом і перевіряє MIME для JavaScript. Додано незалежний початковий скрипт: при помилці модулів або затримці запуску він пропонує повторити запуск чи завантажити програму й не змінює локальні дані.

Для відновлення завислої 1.2.15:

1. Закрийте зависле вікно.
2. У Диспетчері завдань завершіть `Litakova-Komisiia-PC.exe`, якщо він ще працює. Без цього попередній локальний процес може залишатися активним до чотирьох хвилин і знову відкрити старий інтерфейс.
3. Завантажте актуальний EXE з офіційного випуску та замініть попередній файл. Запустіть новий EXE.

Папка `%LOCALAPPDATA%\LitakovaKomisiiaPC` містить збережений стан; її не потрібно видаляти або переносити. Не очищайте кеші й дані облікового запису для цього виправлення.

На програмі 1.2.15, яка не відкриває кабінет, ручне завантаження потрібне, щоб дістатися до робочого інтерфейсу. Для працездатних попередніх версій зберігається чинний підписаний канал автооновлення. Сервер API 20 і навчальні дані цим випуском не змінюються.
